# Mu app icons

The app icons in this directory use Mu branding and replace the Bluesky app icons inherited from
the upstream repository. The upstream Bluesky+ icon variants have been removed.

The repository's MIT software license does not itself grant rights to use Mu's name or branding
as the identity of another product. Forks should provide their own app icons.

See [`ASSETS.md`](../../ASSETS.md) for the repository's full asset licensing inventory.
